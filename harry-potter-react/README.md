## About The Project

[![Harry Potter Logo](./src/assets/images/fantasy-castle.jpg)](https://hp-api.herokuapp.com/)

This project is a **React-based web application** that showcases character details, house information, and more from the magical world of **Harry Potter**. It fetches dynamic data using the [Harry Potter API](https://hp-api.herokuapp.com/) and displays the character's information including their name, species, house, and various magical attributes.

## Getting Started

### Prerequisites

Before installing and running the project, ensure you have the following:

- **Node.js** and **npm** installed. You can download and install them from [here](https://nodejs.org/).

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/TiborKovari/harry-potter-react.git
   ```
2. Navigate to the project directory:
   ```bash
   cd harry-potter-react
   ```
3. Install the dependencies:
   ```bash
   npm install
   ```
4. Start the development server:
   ```bash
   npm run dev
   ```
5. Open your browser and go to [http://localhost:5173](http://localhost:5173) to view the application.

## Usage

- Navigate through the app and explore different character details.
- The `CharacterDetails` page fetches data dynamically based on the character's `id` from the URL.
- Use React Router to navigate between pages such as house listings and character details.
